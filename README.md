# vocabulario-web

This repository contains the source code for [vocabular.io](https://vocabular.io) web frontend

For additional information see [vocabulario-api](https://github.com/vanzay/vocabulario-api)

For service description read the [Help](https://vocabular.io/help) page

## Run locally

```sh
# install dependencies
npm install

# start the server
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```
